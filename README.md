# Kindly App

A human-centered app experience designed for emotional awareness, accessibility, privacy, and dignity.

## Overview
Kindly is a premium, calm, and adaptive mobile experience for people with different needs, contexts, and abilities. It helps users feel supported without pressure and gives them clarity during stressful moments.

## Design direction
- Premium OPPO-inspired gradients and soft glass cards
- Accessible layouts across ages and abilities
- Context-aware UX modes
- Privacy-first settings
- Gentle and respectful support flows

## Tech stack
- Expo
- React Native
- TypeScript
- React Navigation

## Run locally
```bash
npm install
npm start
```

## App highlights
- Adaptive mood check-in
- Accessibility center
- Calm support flow
- Privacy and trust settings
- Human-first UX and low-pressure design
